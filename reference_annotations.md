# Variant Annotations Reference

Reference compiled from `base_data/variantAnnotations/README.pdf` (ClinPGx Variant
Annotations Help File) plus example sentences drawn from the annotation TSVs. Use this
as a quick guide to the field schema and to the shape of the structured sentences the
pipeline must produce/match.

## Overview

The set of files `var_pheno_ann.tsv`, `var_drug_ann.tsv`, `var_fa_ann.tsv` and
`study_parameters.tsv` contain ClinPGx's variant annotations and associated information.
Variant annotations are separated into 3 files because ClinPGx has 3 different
standardized templates to capture information depending on the specifics of the
association. Each file has slightly different fields, though some fields are common to
all 3.

> ClinPGx curators routinely review several high-profile journals for articles to
> curate. There may be more literature in the public domain to support or contradict an
> association that is not in the ClinPGx database. ClinPGx manually curates high-profile
> literature but does **not** contain curated literature from every domain-based journal,
> or all of PubMed. Evidence strength is re-evaluated at non-regular intervals as more
> literature becomes available.

## Common Fields (all three variant annotation files)

These fields appear in `var_pheno_ann.tsv`, `var_drug_ann.tsv`, and `var_fa_ann.tsv`.

| Field | Description |
|-------|-------------|
| **Variant Annotation ID** | Unique ID number for each variant/drug annotation. |
| **Variant/Haplotypes** | dbSNP rsID or haplotype(s) involved. If the association is based on a gene phenotype group (e.g. "poor metabolizers", "intermediate activity"), that gene phenotype appears here. |
| **Gene** | HGNC symbol for the gene involved. Usually the variant is *within* the gene boundaries, but occasionally it is upstream/otherwise associated. |
| **Drug(s)** | The drug(s) involved. If more than one is listed, "Multiple drugs And/or" designates whether it applies to each individually ("or") or the combination ("and"). In `var_drug_ann`, drugs are standardized objects, typically the generic name. |
| **PMID** | PubMed identifier for the supporting article. |
| **Phenotype Category** | One of: `efficacy`, `toxicity`, `dosage`, `metabolism/PK`, `PD`, `other`. |
| **Significance** | Significance as stated by the author: `yes`, `no`, or `not stated`. |
| **Notes** | Free-text notes added by the curator. |
| **Sentence** | The structured annotation sentence generated by the variant annotation tool from the curator's entered fields. |
| **Alleles** | Basis for comparison: a variant, or one or more haplotypes/genotypes/diplotypes grouped together. Blank when a gene phenotype is in "Variant/Haplotypes". |
| **Specialty Population** | Any special populations the annotation is relevant to (e.g. pediatric). |

### Structured-sentence component fields (common)

The following columns are the **parts of the structured sentence** in the "Sentence"
field. Not all fields are required.

| Field | Description |
|-------|-------------|
| **Metabolizer types** | The gene phenotype group, if applicable (e.g. "poor metabolizers"), or genotypes combined into a gene phenotype group. |
| **isPlural** | Maintains grammar in the sentence: `is` or `are`. |
| **Is/Is Not associated** | Whether an association was found: `associated with` or `not associated with`. |
| **Direction of effect** | Descriptor of the measured-term field: `increased` or `decreased`. |
| **Multiple drugs And/or** | If >1 drug: `or` = applies to each drug individually; `and` = applies to the combination. |
| **Comparison Allele(s) or Genotype(s)** | Whether authors directly compared the allele(s)/genotype(s) in "Variant/Haplotypes" against others. |
| **Comparison Metabolizer types** | Whether authors directly compared the gene phenotype group in "Metabolizer types" against others. |

## File-specific fields

### `var_pheno_ann.tsv`

| Field | Description |
|-------|-------------|
| **Side effect/efficacy/other** | Describes the "Phenotype": `likelihood of`, `risk of`, `severity of`, or `age at onset of`. |
| **Phenotype** | Resulting phenotype: a "disease" from the ClinPGx vocabulary, a side effect, an efficacy term, or "other". Free text or an existing (non-standardized) ClinPGx term. Multiple values are comma-separated. |
| **Multiple phenotypes And/or** | If >1 phenotype: separate by `and` or `or`. |
| **When treated with/exposed to/when assayed with** | Connective words between sentence parts (e.g. "when treated with", "when exposed to", "when assayed with"). |
| **Population types** | Type of population studied (e.g. "in healthy individuals", "in children", "in women"). Becomes "...with" when further described by the next field. |
| **Population Phenotypes or diseases** | Disease/phenotype of the studied population (e.g. "diabetes", "lung transplantation"). |
| **Multiple phenotypes or diseases And/or** | If >1 population phenotype: separate by `and` or `or`. |

### `var_drug_ann.tsv`

| Field | Description |
|-------|-------------|
| **PD/PK terms** | The pharmacodynamic/pharmacokinetic phenotype measured; also connects variant and drug in the sentence (e.g. "concentration of", "metabolism of", "response to"). |
| **Population types** | Same as in `var_pheno_ann`. |
| **Population Phenotypes or diseases** | Same as in `var_pheno_ann`. |
| **Multiple phenotypes or diseases And/or** | Same as in `var_pheno_ann`. |

### `var_fa_ann.tsv` (functional analysis)

| Field | Description |
|-------|-------------|
| **Assay type** | Information about the type of assay performed. |
| **Functional terms** | The functional phenotype measured; also connects variant and drug (e.g. "activity of", "expression of", "inhibition of"). |
| **Gene/gene product** | HGNC symbol for the gene (product) measured by the functional assay. Optional; if present, should match the "Gene" field. |
| **When treated with/exposed to/when assayed with** | Connective words (e.g. "when assayed with", "when exposed to", "due to"). |
| **Cell type** | Type of cell in which the assay was conducted (free text). |

## `study_parameters.tsv`

Cross-referenced against the 3 variant annotation files via **Variant Annotation ID**.

| Field | Description |
|-------|-------------|
| **Study Parameters ID** | Unique ID for each "Study Parameters" entry. |
| **Variant Annotation ID** | Matches a "Variant Annotation ID" in one of the three variant annotation files. |
| **Study Type** | `cohort`, `case/control`, `case series`, `cross-sectional`, `clinical trial`, `meta-analysis`, `GWAS`, `replication`, `prospective`, `retrospective`, `linkage`, `trios`. |
| **Study Cases** | Number of cases in the paper. |
| **Study Controls** | Number of controls used in the association analysis. |
| **Characteristics** | Free text: gender, disease, age group, or other distinguishing characteristics of the group studied. |
| **Characteristics Type** | Standardized term for "Characteristics": `disease`, `drug`, `age group`, `gender`, `study cohort`. |
| **Frequency In Cases** | Allele frequency in cases, if clearly reported. |
| **Allele Of Frequency In Cases** | The allele the "Frequency In Cases" refers to. |
| **Frequency In Controls** | Allele frequency in controls, if clearly reported. |
| **Allele Of Frequency In Controls** | The allele the "Frequency In Controls" refers to. |
| **P Value** | The p-value and operator (`=`, `<`, etc.) reported in the paper. |
| **Ratio Stat Type** | `OR` (odds ratio), `RR` (relative risk), or `HR` (hazard ratio). |
| **Ratio Stat** | The number associated with the "Ratio Stat Type". |
| **Confidence Interval Start** | Start of the confidence interval for the "Ratio Stat". |
| **Confidence Interval Stop** | End of the confidence interval for the "Ratio Stat". |
| **Biogeographical Groups** | Population groups from PMID:30506572: `African America/Afro-Caribbean`, `American`, `Central/South Asian`, `East Asian`, `European`, `Latino`, `Near Eastern`, `Oceanian`, `Sub-Saharan African`, `Unknown`, `Multiple Groups`. "Multiple Groups" = study group drawn from more than one biogeographical group (details often included). |

## Example annotation sentences

These are real `Sentence` values from the annotation files, illustrating the structured
templates the pipeline should produce/recognize.

### `var_drug_ann.tsv` — drug dose / response / metabolism

- *CYP3A4 \*17 is associated with decreased metabolism of nifedipine as compared to CYP3A4 \*1.*
- *Genotype TT is associated with decreased response to sitagliptin in people with Diabetes Mellitus, Type 2.*
- *Allele T is associated with increased response to citalopram, escitalopram, fluoxetine, fluvoxamine, paroxetine or sertraline in people with Obsessive-Compulsive Disorder as compared to allele C.*
- *Allele T is not associated with dose of heroin in people with Heroin Dependence as compared to allele C.*
- *CYP2C9 \*3 is associated with decreased dose of warfarin as compared to CYP2C9 \*1/\*1.*

### `var_pheno_ann.tsv` — phenotype associations

- *HLA-B \*35:08 is not associated with likelihood of Maculopapular Exanthema, severe cutaneous adverse reactions or Stevens-Johnson Syndrome when treated with lamotrigine in people with Epilepsy.*
- *Genotypes AA + AT are associated with decreased risk of Tobacco Use Disorder due to nicotine as compared to genotype TT.*
- *UGT1A1 \*1/\*28 + \*28/\*28 is associated with increased severity of Neutropenia when treated with sacituzumab govitecan in people with Breast Neoplasms as compared to UGT1A1 \*1/\*1.*
- *ABCB1 intermediate activity is associated with increased risk of Opioid-Related Disorders when exposed to loperamide.*
- *HLA-A \*02:01 is not associated with increased likelihood of adverse events when treated with ipilimumab, nivolumab or pembrolizumab in people with Melanoma and Metastatic neoplasm.*

### `var_fa_ann.tsv` — functional / in vitro

- *CYP2C19 \*17/\*17 is associated with increased formation of normeperidine as compared to CYP2C19 \*1/\*1 + \*1/\*17.*
- *CYP2B6 \*1/\*1 is associated with increased activity of CYP2B6 when assayed with bupropion as compared to CYP2B6 \*1/\*6.*
- *CYP2C9 \*2 is associated with decreased affinity to CYP2C9 of warfarin as compared to CYP2C9 \*1.*
- *Allele del is associated with decreased transport of ranitidine as compared to allele GAT.*
- *CYP2C19 \*32 is associated with decreased clearance of voriconazole as compared to CYP2C19 \*1.*

## How fields compose into a sentence

A single annotation row decomposes its sentence into the structured component fields.
Example from `var_drug_ann.tsv` (Variant Annotation ID `1448257202`):

| Field | Value |
|-------|-------|
| Variant/Haplotypes | `CYP2C9*1, CYP2C9*3` |
| Gene | `CYP2C9` |
| Drug(s) | `warfarin` |
| PMID | `27488176` |
| Phenotype Category | `Dosage` |
| Significance | `yes` |
| Alleles | `*3` |
| isPlural | `Is` |
| Is/Is Not associated | `Associated with` |
| Direction of effect | `decreased` |
| PD/PK terms | `dose of` |
| Comparison Allele(s) or Genotype(s) | `*1/*1` |
| **Sentence** | **CYP2C9 \*3 is associated with decreased dose of warfarin as compared to CYP2C9 \*1/\*1.** |

Reading the components in order reconstructs the sentence:
`[Alleles] [isPlural] [Is/Is Not associated] [Direction of effect] [PD/PK terms]
[Drug(s)] as compared to [Comparison Allele(s) or Genotype(s)]`.
